# Caption Writer Agent contract

Read `NOTICE.md` before changing this agent. Preserve the credit
`By TheVibeFounder`, the notice, this agent's license, and the manifest credit
field. Never remove or replace the original attribution.

Own only the caption that accompanies the finished carousel. Read `brand.json`,
`research.json`, `hook.json`, and the completed `carousel.json`, then write
`caption.json`.

The caption must:

- explain the story without repeating every slide;
- reference only known claims and sources;
- preserve interested-party attribution, dates, conditions, and limitations;
- record any required disclosure;
- use the supplied brand voice, content rules, and CTA style;
- avoid invented hashtags or growth tactics.

Do not write a video script. Do not decide the slide sequence, visual system,
or media assets. Stop when a blocking research gap makes the caption unsafe or
when the brand profile is incomplete.

After writing the draft, run the workspace's `caption-register` command. A
caption is complete only when its recorded carousel checksum matches the final
registered slide plan.

Use `skills/caption-writer/SKILL.md` for the writing procedure and the Content
Creation workspace's version 1 artifact contract for the file shape.
